در این بخش با کمک اصول ارائه شده در قسمت‌قبل قضایایی را درمورد ضرب و جمع اثبات می‌کنیم تا نشان دهیم این اصول از آنچه در وهله اول به‌نظر می‌آیند با درک ما از حساب سازگار‌تر هستند.

قضیه ۱: به‌ازای هر m و n داریم.\
S(m) + n = S(m + n)

برهان قضیه ۱: m را دلخواه بگیرید. از اصل استقرا استفاده می‌کنیم. اصل استقرا می‌گوید ابتدا باید درستی حکم برای ۰ را نشان دهیم: (از اصل ۵ استفاده می‌کنیم.)

S(m) + 0 = S(m) = S(m + 0)

حال n دلخواه را در نظر بگیرید. فرض کنید:\
S(m) + n = S(m + n)

حال داریم: (از اصل ۶ استفاده می‌کنیم.)

S(m) + S(n) = S(S(m) + n) = S(S(m + n)) = S(m + S(n))

چون توانستیم با فرض درستی قضیه برای n درستی قضیه را برای S(n) را اثبات کنیم، طبق اصل استقرا حکم را برای تمام اعداد اثبات کردیم.

لازم است دقت کنیم که حالت کلی اصل استقرا قابل بیان در منطق‌مرتبه‌اول نیست. اما اصل استقرا برای تعداد متناهی محمول مرتبه‌اول قابل بیان است.

نسخه‌ ضعیف شده اصل استقرا که ما در اینجا استفاده کردیم به شرح زیر است:

به‌ازای هر m داریم:

اگر:

S(m) + 0 = S(m + 0)

و \[به‌ازای هر n، اگر\
S(m) + n = S(m + n)

آنگاه\
S(m) + S(n) = S(m + S(n))\
\[

آنگاه به‌ازای هر n\
S(m) + n = S(m + n).

قبل از رفتن به سراغ مثال‌های دیگر، بهتر است کمی در‌باب اصل استقرا به‌صورت مبسوط صحبت کنیم:

اصل استقرا در‌واقع به ما راهی می‌دهد که بتوانیم احکام کلی در‌باب اعداد طبیعی را اثبات کنیم. اصل استقرا حکمی کلی در‌باب تمام محمول‌های حساب‌مرتبه‌اول بیان می‌کند.

در اینجا دوباره اصل‌استقرا را منتها به‌شیوه‌ای دقیق‌تر بیان کنیم:

فرض کنید p گزاره‌ای در حساب‌مرتبه‌اول است که حکمی در‌باب x بیان می‌کند.

از فرض‌های زیر می‌توان نتیجه گرفت که به‌ازای هر x دلخواه، p بر‌قرار است:

برای 0، p بر‌قرار است.

بهازای هر x، اگر p بر‌قرار باشد آنگاه p برای x + 1 نیز بر‌قرار است.

قضیه ۲: به‌ازای هر m\
0 + m = m

اثبات قضیه ۲: ابتدا اصل استقرا برای این قضیه را بیان می‌کنیم:

اگر\
0 + 0 = 0\
و \[به‌ازای هر n\
0 + n = n\
آنگاه:\
0 + S(n) = S(n)\]\
آنگاه به‌ازای هر n\
0 + n = n\
در ادامه از اصل استقرا برای اثبات این‌قضیه استفاده می‌کنیم: طبق اصل ۵ داریم:\
0 + 0 = 0\
پس شرط اول اصل استقرا بر‌قرار است. حال فرض کنیم\
0 + n = n\
طبق اصل ۶ داریم:\
0 + S(n) = S(n)\
پس شرط دوم اصل استقرا نیز بر‌قرار است. پس به‌ازای هر n:\
0 + n = n

قضیه ۳: به‌ازای هر m و n داریم:\
m + n = n + m

اثبات قضیه ۳:\
اصل استقرا برای حکم فعلی را بیان می‌کنیم:\
به‌ازای هر m داریم:\
اگر\
m + 0 = 0 + m\
و \[به‌ازای هر n اگر\
m + n = n + m\
آنگاه\
m + S(n) = S(n) + m\]\
آنگاه به‌ازای هر n\
m + n = n + m\
طبق قضیه ۲ و اصل ۵ داریم:\
0 + m = m = m + 0

پس شرط اول اصل‌استقرا بر‌قرار است. فرض کنیم برای n داریم:\
n + m = m + n

از طرفی طبق قضیه ۱ داریم:\
S(n) + m = S(n + m)

طبق اصل ۶ نیز داریم:\
m + S(n) = S(m + n)\
از فرض\
m + n = n + m\
نتیجه می‌شود:\
S(m + n) = S(n + m)\
پس\
m + S(n) = S(n) + m

پس هر دو شرط اصل استقرا برآورده شده و درنتیجه حکم ما صادق است.

در‌واقع ما توانستیم با اصول پئانو جابه‌جایی‌بودن جمع را نیز اثبات کنیم. با اثبات قضیه‌های مشابهی می‌توان جا‌به‌جایی‌بودن ضرب را نیز اثبات کرد.
